# Neon Quest

Landing page gamer feita em HTML, CSS e JavaScript.

## Como publicar
1. Suba os arquivos para um repositório no GitHub.
2. Importe o repositório no Vercel.
3. Faça o deploy como projeto estático.

## Destaques
- Hero section forte
- Cards com hover estilo menu de jogo
- Animações ao rolar a página
- Totalmente responsivo
